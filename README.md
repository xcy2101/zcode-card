# Token 奖励弹窗卡片 · 交互演示

复刻 ZCode「领取 1 亿 Token」成功弹窗卡片的前端项目，纯原生 HTML / CSS / JavaScript，无任何依赖，双击即可运行。

## 运行方式

**方式一（最简单）**：直接双击 `index.html` 用浏览器打开。

**方式二（本地服务）**：

```bash
cd token_ui
python -m http.server 8123
# 浏览器访问 http://127.0.0.1:8123
```

## 交互一览

| 交互 | 说明 |
| --- | --- |
| 自动弹出 | 进入页面 0.6s 后自动弹窗，模拟真实领奖场景；关闭后可用页面按钮再次触发 |
| 弹窗入场 | 遮罩淡入 + 卡片弹性放大（overshoot 曲线），内容逐条错峰上浮 |
| 数字滚动 | 金额从 0 滚动到 100,000,000（easeOutExpo 缓动，等宽数字防抖动） |
| 彩带喷发 | Canvas 彩带从卡片中心喷出，带重力、空气阻力、翻转压扁与淡出 |
| 3D 视差 | 鼠标在卡片上移动时卡片随之倾斜，离开后平滑回正 |
| 流光扫过 | 卡片表面每 3.6s 扫过一道高光 |
| 查看明细 | 展开/收起奖励构成明细（高度过渡动画） |
| 领取到账 | 主按钮「开心收下」→ 转圈「到账中…」→ 绿色「✓ 已到账」+ 二次彩带 + 底部 Toast |
| 关闭方式 | 右上角 ×（悬停旋转 90°）、点击遮罩空白处、按 `Esc` |

## 目录结构

```
token_ui/
├── index.html        # 页面结构（演示区 + 弹窗卡片 + 彩带画布 + Toast）
├── css/style.css     # 全部样式与动画
├── js/main.js        # 交互逻辑（彩带引擎 / 数字滚动 / 视差 / 领取流程）
└── README.md
```

## 常用自定义

- **改金额**：`js/main.js` 顶部 `TARGET = 100000000`；
- **改主题色**：`css/style.css` 顶部 `:root` 中的 `--grad-1/2/3` 与彩带颜色数组（`js/main.js` 的 `COLORS`）；
- **改明细**：`index.html` 中 `#detailBox` 的三个 `detail-item`；
- 已适配 `prefers-reduced-motion`（系统开启"减少动态效果"时自动关闭动画）。
