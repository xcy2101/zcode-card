01

技术难点

做这个卡片时真正需要"想一下"的六个问题，以及各自的解法。

难点 1

一个 transform，两个主人

难点：弹窗入场动画 popIn 用 transform 做缩放位移， 3D 视差也要用 JS 写 style.transform——同一个元素的 transform 只有一个"所有权"， 两边同时控制会互相覆盖（倾斜会把入场动画顶掉，反之亦然）。

解法：拆成两层。外层 .reward-card 只承担 CSS 入场动画， 内层 .card-tilt 专门接收 JS 写入的倾斜，CSS 与 JS 各管一层，互不打架。

.overlay.show .reward-card { animation: popIn .55s cubic-bezier(.2,1.4,.3,1) both; } /* 外层 */
.card-tilt { will-change: transform; }   /* 内层：JS 的舞台 */
难点 2

数字滚动：不抖动、可中断、手感好

难点：计数动画常见三个坑——数字宽度不一导致排版抖动；用"帧数"驱动导致不同刷新率速度不一致； 快速重复触发时两套动画叠加跳动。

解法：① font-variant-numeric: tabular-nums 强制等宽数字； ② 用 performance.now() 算时间进度 p∈[0,1]，再经缓动函数映射到数值； ③ 每次开始前 cancelAnimationFrame 掉上一轮的句柄。

const p = Math.min((now - t0) / duration, 1);
const eased = 1 - Math.pow(2, -10 * p);              // easeOutExpo：先冲刺后停靠
el.textContent = Math.round(TARGET * eased).toLocaleString("en-US");
if (p < 1) raf = requestAnimationFrame(frame);
难点 3

彩带：用 2D Canvas 骗过眼睛的"假 3D"

难点：纸片彩带的灵魂在于"翻转时视觉上被压扁"，纯 2D 没有透视可用。

解法：给每个粒子一个持续累加的相位 wobble，画矩形时高度乘以 sin(wobble*2)——正弦缩放就在视觉上模拟出了翻转压缩。加上三个物理量就足够真实： 重力（vy 每帧加常数）、空气阻力（vx、vy 每帧乘 0.985，指数衰减比线性减速自然）、 横向摆动（x 额外叠加 sin 偏移，模拟飘落摇曳）。

p.vx *= 0.985;                    // 空气阻力：指数衰减
p.vy  = p.vy * 0.985 + 0.16;      // 阻力 + 重力
p.x  += p.vx + Math.sin(p.wobble) * 1.2;   // 左右摇曳
const squash = Math.sin(p.wobble * 2) * .6 + 1;  // 翻转压扁 = 假 3D
ctx.fillRect(-p.w/2, -p.h/2*squash, p.w, p.h*squash);
难点 4

高分屏上 Canvas 发虚

难点：Canvas 默认 1 个物理像素对应 1 个 CSS 像素，在 2x/3x 屏上彩带会模糊。

解法：画布物理尺寸放大 dpr 倍，再用 setTransform 把坐标系缩回来， 之后所有绘制代码照常写 CSS 像素。

const dpr = Math.min(window.devicePixelRatio || 1, 2);   // 上限 2，省电
canvas.width  = innerWidth  * dpr;
canvas.height = innerHeight * dpr;
ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
难点 5

渐变描边卡片的两条路

解法 A（本项目）：外壳元素 padding: 1px + 渐变背景，内层元素深色背景盖住中间， 只露出 1px 渐变"边框"。简单直观，还能顺便把阴影、圆角分层处理。

解法 B（单元素）：双背景 + padding-box / border-box 定位， 一条 border 全搞定：

.card {
  border: 1px solid transparent;
  border-radius: 24px;
  background:
    linear-gradient(#161827, #0f111c) padding-box,   /* 内容区填充 */
    linear-gradient(160deg, #fff3, #7c5cff88) border-box;  /* 边框渐变 */
}
难点 6

状态机与防重入：demo 可以无限重玩

难点：弹窗可反复打开、按钮可反复点击，任何残留状态（已领取的绿按钮、展开的明细、滚完的数字） 都会让第二次体验穿帮。

解法：用 isOpen / claimed / detailOpen 三个布尔组成小状态机； openCard() 里把所有 UI 状态完整复位；claimed 后立即 disabled 防重复提交；Toast 重复触发前先 clearTimeout，避免计时错乱。

function openCard() {
  if (isOpen) return;          // 防重入
  claimed = false; detailOpen = false;
  claimBtn.disabled = false;   // —— 以下全是"复位"——
  claimBtn.textContent = "开心收下";
  detailBox.classList.remove("open");
  amountEl.textContent = fmt(0);
  ...
}
02

知识点清单

按 CSS / JS / 交互三组整理，每条都能在项目源码里找到对应实现。

CSS 篇

  • cubic-bezier(.2, 1.4, .3, 1)：控制点 y > 1 会让动画值冲过终点再弹回，弹窗"果冻感"的来源。
  • animation-fill-mode: both：延迟期间应用首帧、结束后保持尾帧，错峰入场不会先闪现。
  • backdrop-filter: blur()：遮罩毛玻璃，需配半透明背景色。
  • background-clip: text + color: transparent：渐变文字。
  • text-shadow 对透明文字依然绘制：渐变字也能有光晕。
  • mask-image 径向渐变：让背景网格向边缘淡出，零图片。
  • :not() 排除 + nth-child 递增 delay：错峰入场（stagger）。
  • max-height 0→N 过渡：展开收起；进阶方案 grid-template-rows: 0fr→1fr 免估高度。
  • will-change: transform：提示浏览器建合成层，别滥用。
  • @media (prefers-reduced-motion)：尊重系统"减少动态效果"。

JS / Canvas 篇

  • requestAnimationFrame 时间驱动：按时间戳算进度，与刷新率解耦。
  • 缓动函数 = 进度的非线性映射：换一个函数就换一种"手感"。
  • lerp 插值 cur += (target - cur) * 0.12：视差/跟随/惯性的万能公式。
  • 指数衰减阻力 vx *= 0.985：比线性减速更自然的粒子运动。
  • 正弦缩放模拟 3D：2D 里"骗"出翻转透视。
  • devicePixelRatio 适配：Canvas 高清三件套（放大物理尺寸 → setTransform → 照常画）。
  • ctx.save()/restore() + translate/rotate：局部坐标系互不污染。
  • RAF 按需启停：粒子清空后 cancel，避免看不见的空转耗电。
  • 定时器句柄成对管理：cancel 旧的再开新的，快速连点不叠帧。

交互与无障碍篇

  • e.target === overlay 才关窗：点击卡片内部会冒泡到遮罩，必须判断真实点击目标。
  • role="dialog" + aria-modal + aria-labelledby：读屏软件眼中的模态框。
  • aria-hidden 与视觉状态同步切换。
  • Esc 全局监听：模态框标准逃生通道。
  • 按钮三态：默认 → loading（spinner + disabled）→ success（变色 + ✓），杜绝"点了没反应"。
  • Toast 替代 alert()：非阻断提示，重复触发先 clearTimeout。
  • 状态复位：重开即还原，演示才能无限重玩。
  • 错峰入场：元素依次出现比整块出现更有质感，成本只是几个 delay。
03

动画样式速查

9 个可以直接抄走的动画/交互样式，全部来自项目真实代码，点「重播」或按提示操作现场体验。

💡 重播 CSS 动画的通用套路：先 classList.remove() 移除动画 class → void el.offsetWidth 强制重排重置动画 → 再把 class 加回来。

① popIn 弹性入场

弹窗出场的主力动画。核心是贝塞尔曲线第二个控制点 y=1.4：值冲过 1 再回落，产生"果冻"般的过冲回弹，比 ease-out 有生命力得多。

animation: popIn .55s cubic-bezier(.2, 1.4, .3, 1) both;
@keyframes popIn {
  from { transform: scale(.7) translateY(40px); opacity: 0; }
}
弹窗卡片

② rise 错峰上浮（stagger）

卡片内容逐条出现。每个子元素同一段动画，仅 nth-child 递增 0.05s 延迟；fill-mode: both 保证延迟期间保持首帧的透明。

.overlay.show .card-tilt > *:not(.shine) { animation: rise .55s ease both; }
.overlay.show .card-tilt > :nth-child(5) { animation-delay: .18s; }
图标标题按钮

③ sweep 流光扫过

一条斜向高光带从左扫到右，模拟玻璃反光。关键：渐变带透明区收尾 + translateX 平移，overflow: hidden 裁剪。项目里设为 infinite 循环、延迟 1.2s 起。

.shine { transform: translateX(-120%); animation: sweep 3.6s ease-in-out 1.2s infinite; }
@keyframes sweep { 55%, 100% { transform: translateX(120%); } }
卡片表面

④ floaty 悬浮 + twinkle 闪烁

奖励图标上下悬浮（transform 循环），两颗星点错相位闪烁（scale + opacity + animation-delay）。常驻动画费用极低，纯 transform/opacity 不触发重排。

.icon { animation: floaty 3s ease-in-out infinite; }
.spark { animation: twinkle 1.8s ease-in-out infinite; }
.spark:last-child { animation-delay: .9s; }  /* 错相位 */
⚡

⑤ 按钮微交互三件套

悬停 translateY(-2px) + 阴影增强 = "浮起来"；按下 scale(.97) = "按下去"；圆形关闭钮悬停 rotate(90deg)。鼠标移到右侧按钮上感受。

.btn:hover  { transform: translateY(-2px); box-shadow: 0 12px 30px ...; }
.btn:active { transform: translateY(0) scale(.98); }
.close:hover { transform: rotate(90deg); }

⑥ 展开收起（max-height 过渡）

max-height: 0 → 170px 配合 opacity，transition 自动补间。注意要预估一个够用的上限值；要求更精确可改用 grid-template-rows: 0fr → 1fr。

.detail { max-height: 0; opacity: 0; overflow: hidden; transition: max-height .4s ease, opacity .35s; }
.detail.open { max-height: 170px; opacity: 1; }

⑦ 数字滚动 count-up

时间驱动 + easeOutExpo 缓动 + tabular-nums 等宽数字。先快后慢的"冲刺停靠"节奏比匀速计数更有获得感的爆发感。

const p    = Math.min((now - t0) / duration, 1);
const eased = 1 - Math.pow(2, -10 * p);   // easeOutExpo
el.textContent = Math.round(target * eased).toLocaleString();

⑧ 彩带喷发（点击画布）

完整粒子系统：扇形初速、重力、空气阻力、摆动、翻转压扁、寿命淡出，粒子清空后 RAF 自动停止。点击右侧画布任意位置，从点击点喷发。

const angle = -Math.PI/2 + (Math.random() - .5) * Math.PI * 1.1;  // 向上扇形
const speed = power * (.4 + Math.random() * .8);
pieces.push({ x, y, vx: Math.cos(angle)*speed, vy: Math.sin(angle)*speed, ... });
点击画布喷彩带 🎉

⑨ 3D 视差倾斜

鼠标位置归一化到 -0.5~0.5 映射为旋转角，再用 lerp 每帧向目标角度插值 12%——平滑跟随的关键。鼠标移到右侧小卡片上体验。

ry = ((e.clientX - r.left) / r.width - .5) * 10;   // 归一化 → 角度
cur += (target - cur) * .12;                        // lerp 跟随
tilt.style.transform = `perspective(900px) rotateX(${rx}deg) rotateY(${ry}deg)`;
